# iptv-nas 协作约定

> 2026-09-25：本项目已并入 kantv 仓库，现为 `kantv/server/`；原上级目录的 `PROMPT_iptv-nas.md` 不再随项目走，红线与本文件及 `docs/HANDOFF.md` §5 为准。

家庭自用的直播列表与接口服务端（Python，跑在家庭 NAS 容器内），为局域网 Android TV 客户端 `kantv`（同仓库 `app/`）提供播放列表、频道归因与接口服务。**它正在服役**——家人的电视此刻可能就靠它播放：生产环境只读，要写生产先回来问用户；不得删除文件；不得对外暴露服务；不得创建或轮换令牌。

本文件目前只维护一条项目级约定（其余红线与工作流见项目 `docs/HANDOFF.md` 与 `docs/`）：

**凭据只交给工具去用，不许取到自己手里（用户明确要求）**：需要凭据时（`config/` 下的令牌与密钥、接口 securitykey / clearkey、镜像仓库或 NAS 登录信息）一律让工具自己完成认证，不要读出来再自己发请求。判据只有一句："要不要把凭据拿到自己手里"——要拿到就是越界。发现敏感内容**只报告路径与性质，绝不报告内容**。理由：agent 读到的东西会进入会话上下文并随请求外发，凭据一旦泄露不可逆；"我不会打印出来"只是自律，不是安全边界。只有用户逐次点名批准时才可以读，且必须一次性使用，不得出现在日志、报告、命令输出或任何文件里。
