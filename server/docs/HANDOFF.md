# 服务端维护交接

## 1. 项目与入口

服务端代码位于 KanTV 的 `server/`。Python 标准库应用由 `app/main.py` 装配，公开运行环境通过 [部署说明](../deploy/README.md) 初始化。个人旧运行记录和真实部署参数私有保留，不属于公开交接文档。

## 2. 配置与数据

公开样例不含播放源、DRM 凭据或反馈配对。实际 settings、令牌、数据库、seed、输出和日志保存在被忽略的实例目录。`app/config.py` 提供默认值；不能将运行数据复制进镜像或测试 fixture。

## 3. 契约与验证

接口契约唯一副本为 [HUB_CONTRACT_V1.md](HUB_CONTRACT_V1.md)，变更记录见 [HUB_CONTRACT_CHANGELOG.md](HUB_CONTRACT_CHANGELOG.md)。离线验证使用 `python3.12 server/tests/run_offline.py`，不读取任何本机私有配置。真实载荷与权威向量按客户端门禁要求在临时目录注入，不进入 Git。

## 4. 运行与发布

默认仅本机可达。需要电视访问时显式绑定 LAN，并检查网络边界；Hub 只读端点的现有设计不能当作公网认证方案。改动先通过本地、CI、候选与实际用户验收；未执行的阶段不得写为完成。公开源码整理不自动部署现有实例。

## 5. 安全边界

凭据由工具读取和使用，不回显、不写报告、不提交，不创建或轮换令牌。生产实例和 NAS 操作需符合当前任务授权；不得删除数据、修改无关服务或对外暴露服务。发现可能敏感的材料只报告路径与性质，不展示其值。
