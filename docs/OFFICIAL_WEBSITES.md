# 官网频道与添加来源

客户端可以独立使用。首次启动会自动准备应用已适配的官网频道目录，不需要家庭配置、M3U 文件或 NAS 服务。目录保存在本机；存在频道条目不等于官网当前在每台设备、每种网络下都能播放。

## 选择网站和频道

1. 打开应用设置，进入“选择官网频道”。
2. 选择央视频、广东荔枝网或第一财经官网。
3. 勾选需要的频道，或全部选择，再确认添加。取消不会写入目录。
4. 返回频道列表选台。添加来源不会自动切换正在播放的频道；重复添加会合并已有来源。

频道选择页展示应用已适配的目录，不会扫描全站、解析任意视频或增加后台播放监测。首次安装已经具备这些内置条目，因此再次添加同一频道不会增加重复频道。

## 粘贴官网地址

设置中的地址输入框同时支持自己的 M3U/TXT 订阅和已支持的官网页面。

| 网站 | 入口示例 | 导入结果 |
| --- | --- | --- |
| 央视频 | `https://www.yangshipin.cn/tv/home` | 打开央视频的已适配频道目录 |
| 央视频频道 | `https://www.yangshipin.cn/tv/home?pid=600001859` | 添加对应的 CCTV-1 频道 |
| 广东荔枝网 | `https://www.gdtv.cn/` | 打开广东荔枝网的已适配频道目录 |
| 广东频道 | `https://www.gdtv.cn/tvChannelDetail/43` | 添加对应的广东卫视频道 |
| 第一财经首页 | `https://www.yicai.com/` | 打开第一财经官网的已适配频道目录 |
| 第一财经频道 | `https://www.yicai.com/tv` | 添加对应的第一财经频道 |
| 东方财经 | `https://www.yicai.com/tv#dfcj` | 添加对应的东方财经频道 |

普通央视频频道链接不需要添加应用专用标记。导入后仍保存既有的标准频道页面身份，不把临时媒体地址保存为永久订阅。

不支持的频道标识、冲突的频道参数和未适配的官网页面会被拒绝；不会默认跳到另一个频道。只支持准确的官网主机和 HTTPS 页面，仿冒域名不属于官网。M3U/TXT 的下载、订阅刷新和文件导入保留原有流程。

## 分组与来源合并

不单列“财经”分类。CCTV-2 财经仍归央视，TVB 财经仍归港澳台；第一财经和东方财经归“第一财经官网”。

官网和 M3U 来源使用现有频道身份规则合并。能明确识别为同一频道时，保留原频道位置和其他来源；不能仅凭“新闻”等通用名称猜测两个频道相同。添加官网频道不会修改已有订阅地址，也不会删除用户的其他频道。

## 播放与验收范围

官网的登录、会员、地区和设备限制仍然有效。网页出现一个频道或显示“限免”，不代表所有用户始终可看；新出现的官网频道也不会自动成为已适配频道。网站改版后可能需要更新适配。

M3U 和 NAS 都是可选扩展：M3U 用于导入自己的播放来源；NAS 用于集中拉取、检测、筛选和生成列表。只使用官网频道时无需配置 NAS。

构建、单元测试和模拟器中的目录导入检查用于验证代码与交互。实际设备持续播放和音画体验需要另行验收，遵守 [播放稳定性约定](PLAYBACK_STABILITY.md)。本功能不会替换家庭稳定入口，也不包含 APK 发布。
