# 自托管更新发布检查

配置与工具用法见 [发布工具说明](../tools/lan_release/README.md)。每个实例使用自己的应用 ID、签名证书、SSH 目标、目录与端点；公开源码没有预设的家庭部署。

1. 核实目标身份、应用 ID、当前两个清单、候选版本必须单调增加、签名证书一致，旧 APK 与回滚清单完整。
2. 运行相关单测、构建、Lint、隐私检查和正式签名验证。凭据只从工具注入，不保存在项目、输出或日志中。
3. 默认只上传版本化不可覆盖候选。相同文件名不同内容、同版或降级应拒绝，上传中断不得影响稳定入口。
4. 在相同实际设备和线路上完成基线/候选持续播放、换台、恢复及本次影响的验收。记录条件差异和脱敏证据。
5. 只有验收通过且用户明确要求后才执行受控切换；保留旧 APK、清单快照和回滚办法。双清单不能视为文件系统级单操作，强杀/断电须按保留快照核对恢复。
6. 分开记录本地、CI、合并、部署、完整 APK 下载及真实用户验收。网络下载成功不能替代可见播放或音画同步。

家庭原始 v53 入口与资料私有保留，本开发流程不会自行替换它们。
