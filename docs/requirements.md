# 看电视：需求基线

更新日期：2026-09-08。以用户最新回答为准；“建议”和“待核实”不得当作已确认。

> **进度注记（2026-09-28）**：本文为最初的需求基线。P0–P2 已完成，客户端已到 v0.2.30（含枢纽订阅、EPG 浮层、Gecko 镜像模式）；两台设备 ABI 已实测（TCL=arm64-v8a、极光盒子 5X=armeabi-v7a）。当前实现与验收状态以发布记录为准，本文不再逐版更新。

## 已确认

- 项目名称 kantv；显示名称“看电视”；主要用户为老人，家人管理频道；家庭自用。
- 目标设备为 TCL Q10M Pro 和极光盒子 5X。两台设备分别验收。
- 完全从零开始，不移植 StreamTV 或其他旧项目代码。
- 先下载官方 TiviMate 安装包分析；参考其频道浏览、节目表、播放控制、遥控器导航和设置组织方式，以独立代码和原创素材实现。
- 用户会准备合法来源的播放列表，包含 M3U 等正规格式；不内置真实频道或凭据。
- 已配置情况下启动恢复上次频道并全屏播放。
- 遥控器行为跟随 TiviMate：以指定参考版本的实际观察为准，无法确认的按键不凭印象定义。
- 界面简洁：正常观看只保留必要电视信息；技术参数和详细信息放设置。
- 不需要 PIN，不需要手机配置，不增加老人/高级模式切换负担。
- 新增确认：同时参考 TiviMate 与 Kodi 的直播操作和播放能力设计；完全从零实现的边界不变。
- 新增确认：播放底部控制栏出现时，返回键先关闭控制栏并留在全屏播放；无浮层时再按返回才进入节目表。
- 最新确认：全屏确认键也打开频道列表；设置补齐节目单（EPG）、台标及预设选择。具体预设服务和刷新周期仍为建议。
- 允许下载 Kodi 官方源码分析并评估成熟开源内核复用；原创应用与交互不意味着重写成熟解码库。具体内核以源码评估和目标设备对照测试决定。
- 用户认为目前其余操作逻辑暂时没有问题，按现有原型继续；不重复请求全套交互确认。
- 先交付可操作原型：正常播放、加载、空列表、无节目单、播放失败均需展示。
- 分阶段交付可安装版本，优先导入、频道列表、真实播放、遥控换台、状态保存。
- 回看、时移、录制、多画面等候选功能继续保留在总清单中，分期不代表删除。
- 应用业务、名称、图标与视觉素材独立实现；允许按相应许可接入成熟开源播放组件；参考 APK 与解析结果只作为本机研究资料。
- 日志、截图、报告不包含真实播放地址、认证参数或凭据。
- NAS 服务端已深度参与：枢纽订阅、回流、EPG 数据由 `server/`（原 iptv-nas）提供；NAS 变更走独立授权与部署流程。

## 待确认或待核实

| 项目 | 当前状态 | 处理方式 |
|---|---|---|
| 两台设备实际系统版本、CPU 架构、可用存储 | 待读取 | 进入安装阶段读取，型号本身不能证明兼容 |
| 实际源协议、请求头、连接数、节目单来源 | 用户准备中 | 先用无凭据的本地合成样例进行交互验证；真实源就绪后脱敏检查 |

| 回看、时移、录制和多画面的源及设备条件 | 未知 | 各自做能力判断，不预先承诺 |

## 建议默认值（尚未作为用户确认要求）

- 初次没有源时显示简短配置引导；导入失败保留已有可用频道。
- 换台短暂显示频道名称和当前节目，数秒后隐藏；正常播放不常驻调试参数和按钮提示。
- 无节目单只提示暂无节目，不阻止播放。
- 播放失败提供重试和换频道，自动重试有上限，避免无限转圈。
- 首期以 M3U/M3U8 列表和 XMLTV 为目标；其他来源格式根据用户实际样例决定。
- Android 原生电视应用，播放内核优先评估 AndroidX Media3；最终版本和兼容配置以开发阶段官方文档及实测为准。
- 首期本地保存频道、分组、收藏、观看状态和配置；不引入云账号。

## 开发阶段

1. P0：官方参考下载与分析、完整功能对照、遥控规则与设备信息整理。
2. P1：可操作原型，覆盖五种状态；参考行为尚未验证处显式标注。
3. P2：可安装基础版：M3U 导入、频道列表与分组、真实播放、换台、上次频道和状态保存、基础异常恢复。
4. P3：频道管理与节目表：多列表管理、收藏、排序隐藏、EPG、频道/节目搜索、最近观看。
5. P4：音轨字幕、画面比例、遥控设置、备份恢复、长时间播放与断网恢复完善。
6. P5：按依赖分别实现回看、时移、录制、多画面。每项独立验收，未具备条件时保留为待实现。

## 验收记录规则

每次交付分别报告：代码与自动检查、安装包构建、模拟器验证、TCL 真机、极光盒子真机。

真机记录首次出画面时间、连续换台耗时与失败数、长时间播放卡顿、音画同步、焦点移动、断网恢复、退出重进、解码与设备兼容性。建议先短测，再至少两小时连续播放；具体门槛先测基线后确认。

参考 TiviMate 在模拟器中的表现，不能算 kantv 已通过验证；合成测试画面也不能算真实频道直播通过。
