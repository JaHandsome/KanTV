观察日期：2026-09-08；TiviMate 5.3.3；官方直接下载版；免费状态；Android TV API 34 arm64 临时模拟器；默认配置；无账号；三个虚构频道和本机合成 TS；无真实 EPG。

## kantv 原型如何采用

2026-09-08 用户修正：底部播放控制栏打开时，返回键只关闭控制栏，保持当前频道全屏播放；再次返回才到节目表。此规则明确优先于任何原版参考行为。其余当前交互暂按原型继续，不代表深层播放能力已经验收。

- 采用已经观察的层级：全屏→左侧频道列表；全屏→播放控制；全屏返回节目表；节目表→分组→主导航→设置。
- 频道列表方向键选台，确认后全屏；节目表保留预览后进入全屏的过程。
- 用户最新指定：全屏确认键与左键都打开频道列表；上下选台，确认后回全屏。此为 kantv 的明确设计，和原版观察分开记录。上下直接换台仍未采用。
- 用户已指定的差异优先：启动恢复上次频道全屏，正常观看简洁，调试/技术详情放设置，不加 PIN 和手机配置。
- 合成节目、错误恢复和设置细节在原型里用于设计演示；尚未经过原版观察的部分标为 kantv 草案，不能宣称完全复刻。
- 原型所有“播放”“导入”“恢复”均是本地交互模拟，不是真实播放器、磁盘持久化或文件导入功能。
